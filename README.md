# Weather Dashboard

A Java-based weather dashboard that fetches weather data from OpenWeatherMap and presents it in a Swing desktop UI. The project also includes a browser demo version with mock weather data.

## Overview

This app lets users:

- search by city name
- switch between Celsius and Fahrenheit
- view current temperature, humidity, wind, and weather description
- refresh weather data manually
- use demo data when no API key is available

## Tech stack

- Java 17
- Maven
- Swing for desktop UI
- org.json for API response parsing
- JUnit 5 for regression testing

## Features

- Live weather lookup using OpenWeatherMap
- Demo mode fallback when `OPENWEATHER_API_KEY` is not set
- Condition-based weather icons
- Temperature conversion between °C and °F
- Refresh button for updated data
- Clean separation between model, UI, and service layers
- Automated tests for parsing and icon mapping

## Run the Java desktop app

From the project root:

```powershell
$env:JAVA_HOME = "C:\Program Files\Microsoft\jdk-17.0.20.101-hotspot"
$env:Path = "$env:JAVA_HOME\bin;C:\Tools\apache-maven-3.9.9\bin;$env:Path"
mvn clean compile
mvn exec:java -Dexec.mainClass=com.weatherapp.Main
```

If you are using a normal local Java + Maven setup, the shorter version is:

```bash
mvn clean compile
mvn exec:java -Dexec.mainClass=com.weatherapp.Main
```

## API key setup

To use the live OpenWeatherMap service, set the environment variable:

```powershell
$env:OPENWEATHER_API_KEY="your_api_key_here"
```

Then run the app again. If the variable is missing or blank, the app automatically uses demo weather data.

## Notes

- The desktop app uses Swing and requires a graphical environment.
- The browser version is a frontend mock/demo and does not talk to the Java backend.
- The project is intentionally structured for easy extension with additional weather providers or a richer forecast model.
